# Questions & Answers

Answers describe `conscious-agent` 3.x. The precise mathematics is in [MATHEMATICAL_MODEL.md](MATHEMATICAL_MODEL.md). Earlier versions of this page made claims that did not survive scrutiny; they are listed under [Corrections](#corrections).

---

## What this project is

### Q1: What is this library?

It is an executable model of Donald Hoffman's *conscious agent* formalism, in Node.js and Python, with identical behaviour in both. It contains:

- **`FormalConsciousAgent`**: the six-tuple (X, G, P, D, A, N) of Hoffman & Prakash (2014) as explicit Markov kernels, with the joint dynamics on experience × world, stationary distributions, and combination.
- **`ConsciousAgent`**: a learning agent that builds its kernels from experience. It uses an experience trie (world model), a meta-trie (a Markov chain over its own self-observations), an "I" attractor that locks onto a dominant self-state, and a lexicon.
- **Analysis tools**: ergodic diagnostics, spectral dimension, irreversibility, and Bell/CHSH classification.
- **Experiments** (`examples/`), each with controls, that test specific claims.

### Q2: Is the agent conscious?

The code cannot answer that, and nothing in it is evidence either way. It implements a *formal structure* that Hoffman proposes as a model of conscious agents. Whether that structure is conscious is a philosophical question about the theory, not an empirical property of the program. Outputs such as `I notice I familiar` are generated by a fixed rule once the "I" locks (see Q6); they are not reports of experience.

### Q3: What does the library let you do that a paper cannot?

It makes the theory's claims computable. For any finite agent network you can compute exactly what the theory implies: its stationary behaviour, its mixing, what an observer at the interface would see, and which correlations it can produce. You can then compare that with controls. Experiments 13 and 14 are examples of turning a qualitative claim into a quantitative, falsifiable one.

## Architecture

### Q4: How are private experience spaces handled?

Each agent owns its tries, meta-trie and lexicon. World states are identified by hashing what the agent observes: the first 4 bytes of SHA-256, the same in both languages. Meta-states are hashed coarse self-observations. Two agents can use the same id only for the same observation; what that id *means* to each agent is its own transition structure.

### Q5: What happens to agents when they are combined?

`combine(A, B)` creates a new agent. The originals are not modified.

- **Identity.** The combined id depends only on the set of leaf constituents, so A ⊗ B = B ⊗ A and (A ⊗ B) ⊗ C = A ⊗ (B ⊗ C). This is the *undirected* (independent-product) join. Order-dependent *directed* joins, where one agent's actions feed another's perceptions, are not implemented.
- **Self.** The combined agent starts with an empty self-chain and an unlocked "I". The constituents' histories are kept under collision-free provenance ids.
- **Fusion.** `fuse()` restores each constituent exactly (verified in example 02 and the unit tests).
- **Product kernel.** `productKernel(A, B)` gives M_A ⊗ M_B, the independent-combination prediction.

### Q6: How does the "I" attractor work?

Every 20 steps the agent observes itself. The coarse self-observation has three parts: its last two world states mod 8, a bucket for its recent prediction error, and its current output mode. It records the transition from its previous self-state. On the recurrent class of this chain it computes the stationary distribution, period and mixing.

"I" locks when, for 3 consecutive observations, all of these hold:
- there is enough data;
- the chain is aperiodic and converged;
- one self-state dominates well above the uniform baseline;
- the agent currently occupies that recurrent class;
- the dominant state is stable.

It unlocks with hysteresis when dominance collapses. Measured behaviour: 0 of 50 structureless worlds lock, 20 of 20 worlds with a dominant attractor lock (around steps 460–600), and agents unlock after a regime change. See MATHEMATICAL_MODEL.md §5.

Once locked, the agent's output follows the decision kernel D over four modes (core, lexicon, explore, idle). The `core` utterance is always `I notice I <familiar|different>`.

### Q7: Why these lock parameters?

`lockMargin = 0.15` (dominance above uniform), `minTransitions = 20`, `minTransitionsPerState = 2` and `minOccupancy = 0.6` were chosen so that structureless worlds never lock (null test) and single-attractor worlds always do (positive test). Both tests run in CI. They are engineering choices, not derived from the theory; all are configurable.

## Results

### Q8: What has the project actually found?

Each result has a control and a unit test.

| Result | Where |
|---|---|
| **The "I" lock separates structure from noise.** It fires in attractor worlds, never in noise, and releases after a regime change. | `test/ilock.test.js`, example 12 |
| **Bell test through the headset.** If a conscious-agent network sits behind spacetime and an observer's action can reach it, the best CHSH value is **exactly 2 + 2·δ(Qᵏ)**, where δ is the network's contraction coefficient after k steps (proved, and attained numerically). Correlations reach the PR box (4) at zero network distance, pass Tsirelson's bound 2√2 when δ ≤ √2 − 1, and become classical as the network mixes. Nothing in the kernels singles out quantum correlations, and without an extra no-signalling rule, 98% of random networks would signal. | example 13 |
| **Spacetime in the headset.** An agent that sees only opaque symbols recovers its hidden world's dimension from experience (within 0.03). Under ⊗, dimension adds exactly (three combined 1-D agents form a 3-D space). Interaction binds dimensions (3 → 1 as coupling grows) and creates an arrow of time (irreversibility 0 → 0.41). Geometry is inherited from agent dynamics, not generated. | example 14 |
| **Time in the traces.** An observer restricted to part of the network experiences exactly the trace chain of its window (Hoffman's trace logic). Its clock runs at π(S) ticks per network step (Kac), and nested observers' clocks compose exactly. With reversible dynamics every observer's uncertainty about its future still grows: the arrow of time comes from observing. A window of two states never perceives an arrow of time. Example 18 takes these clocks to the n → ∞ limit. | example 15 |
| **Trace logic and decorated permutations.** Hoffman's map from Markov chains to decorated permutations (the combinatorics of the positive Grassmannian) agrees with all 27 entries of the paper's own table. That table lists 14 distinct permutations for 3-state agents, not the 17 the text states. σ discards all probabilities and depends on the cyclic order in which experiences are numbered, so a route to particle physics needs a principle that fixes that order. Trace logic behaves as claimed: locally Boolean, globally not a lattice, and mapped into Lebesgue logic by the stationary measure. The proposed readings of mass as entropy rate and speed via commute time pass first consistency checks. | example 16 |
| **Quantum agents.** With complex amplitudes (quantum channels), combined agents reach Tsirelson's bound 2√2 exactly and never exceed it (2000 random interactions), and no-signalling holds automatically. The Hilbert-space structure does this work, not the agent formalism, so it answers example 13 by assumption. Markov agents are the fully decohered quantum agents: dephasing brings CHSH down to exactly 2 and removes interference. Quantum agents show two-route but never three-route interference (Born rule). | example 17 |
| **Relativity at infinity.** Hoffman conjectures that relativity emerges from agent chains as n → ∞. In a 1+1-dimensional model with one bit of memory (the agent's direction), a light cone survives the limit (a memoryless agent's speed diverges). The clock that counts the agent's own changes of experience converges to Einstein's proper time: at speed 0.6 it reads 0.800, and at speed 0.8 it reads 0.600. Every finite network keeps a preferred frame, with errors ∝ 1/n. The classical dynamics keeps the network's rest frame, while complex amplitudes give the Lorentz-covariant Dirac propagator, with mass as reversal rate. This is known mathematics (Goldstein, Kac, Feynman's checkerboard) read as agents. | example 18 |
| **Exchange symmetry.** Combination is exactly symmetric under swapping constituents. That follows from the operator's definition; it is not an emergent result. | example 07 |
| **Observer-gated combination** produces order-dependence when one agent's history predicts the other's better. | example 08 |
| **No interference from classical probability.** The Markov machinery cannot produce double-slit interference; complex amplitudes would be needed. | example 09 |
| **Interface compression.** A coarse "interface" perception can predict better than a fine-grained "truth" perception in a world with irrelevant within-group variation. This is consistent with, but much weaker than, Hoffman's fitness-beats-truth theorem. | example 01 |

### Q9: Does the library show quantum behaviour?

The Markov agents do not: every chain they run is a classical stochastic process. Two earlier claims are withdrawn: the "quantum algebra convergence" and the "spectral gap collapse" (see Corrections). Example 02 shows why they were artifacts: a plain classical clock meets the old "quantum-like" criterion. Example 13 shows what the formalism *can* do. Granting a network behind spacetime, it can produce non-local correlations at the interface, but it does not by itself select the quantum ones. Example 17 adds *quantum agents*, whose kernels are quantum channels. They reach exactly the quantum limit, but only because quantum structure is built in.

### Q10: Does it show spacetime emerging?

Not in the sense of geometry appearing from nothing. Example 14 shows that observers recover geometry that is present in the agent dynamics, and that combination and interaction add and bind dimensions in precise ways. Which principle would select three weakly coupled spatial directions plus an arrow of time is open. It is the concrete question the "spacetime is a headset" view needs to answer.

### Q11: How does this relate to Integrated Information Theory?

There is no formal comparison yet. A natural test is to compute Φ, or a simpler integration measure such as the divergence between a combined agent's learned kernel and the product kernel of its constituents, for agents vs. controls. Example 02 already shows that learned joint dynamics differ from the product prediction (mean |Δgap| ≈ 0.09). Whether that difference deserves the name "integration" needs controls and a pre-registered prediction.

## Robustness and limitations

### Q12: Are results reproducible?

Yes. Agents accept a `seed` (mulberry32), and all hashing is specified bit for bit. The parity tests require Node and Python to produce identical agent dynamics, lock events, combination and fusion. Every experiment's output is identical in both languages. Unseeded agents use `Math.random` / `random.Random` and are not reproducible.

### Q13: What are the known limitations?

- **No forgetting.** Transition counts never decay, so unlocking after a regime change is slow.
- **Coarse meta-states.** The coarse self-observation loses information, and hashing into 28 bits can collide.
- **Discrete worlds only.** Continuous data must be binned (`WorldBuilder`).
- **Transitions, not rules.** The trie learns transitions, not functions: it does not generalise to unseen states.
- **Mode-dependent loop score.** `strangeLoopScore` measures time spent in the `core` output mode, not emergent self-reference (see Corrections).
- **React Native.** The React Native package still uses the 2.x math.

### Q14: What is the most important experiment not yet run?

**A self-reference ablation on a quantitative outcome.** Replace the conscious agents in examples 13 and 14 with Markov chains that have the same transition kernels but no self-model and no "I". Every result in those experiments depends only on the kernels, so they will be unchanged. That is the precise sense in which *these* results do not yet use the "conscious" part of the model. A result that changes when self-reference is removed would be the first evidence that it is load-bearing.

## Corrections

Earlier versions of this page, the README and the project site made the following claims. They are withdrawn.

| Earlier claim | Why it was wrong |
|---|---|
| "Quantum algebra convergence": combined agents' spectra converge toward a tensor product | The analysed matrices contained disconnected pieces and artificial absorbing states; the gap was 0 by definition. Measured correctly, learned joint dynamics do not match the product prediction (example 02). |
| "Spectral gap collapse and broken detailed balance are a quantum-like signature" | A classical clock satisfies both (example 02, classical controls). |
| "Self-reference is causally necessary for identity (100% vs 0% lock)" | The OFF condition set a threshold no chain can reach, so 0% was guaranteed by construction; the ON condition locked in every world, including pure noise, because of a stationary-distribution bug. |
| "Lock time is exactly 60 steps" | That was the earliest possible time, reached in every world because of the same bug. v3 locks only on real attractors. |
| "Lock rate stays at 100% even at 1024 agents" (Planck probe) | Same bug: the old lock fired regardless of structure. |
| "~64 qubits would reproduce these effects on quantum hardware" | Based on the withdrawn quantum claims. |
| "Hoffman & Prakash derive Minkowski spacetime" | Overstated. Their published results are mathematical correspondences (a quantum free-particle wave function has the form of the harmonic functions of conscious-agent dynamics, 2014; a map from Markov chains to decorated permutations, 2023) within a research program. |
| "strangeLoopScore is the observable signature of self-awareness" | The score is fixed by the output mode: the `core` utterance always scores 1.0. |
| "Combination is non-commutative" | The implemented operator is commutative by design (Q5). |
| Mini Brain oscillations, 90% shared meaning, LLM-parent labelling, 7-domain results | These referred to experiments outside this repository that were run with the 2.x math. They cannot be reproduced here and should not be cited as results of this library. |
